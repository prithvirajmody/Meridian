# M3 demo — intelligent & multi-domain (Phase 9)

*The milestone claim (ROADMAP §M3): three structurally different domains
live against one frozen contract — tree-ish markdown, dense-graph code, and
AI-extracted discourse — with AI-derived structure flowing through the same
pipeline as parsed structure: same proposals, same deltas, same provenance,
same zoom.*

Recording: `docs/demos/m3.webm` *(recorded at the M3 review — pending)*.
Every command below is copy-pasteable from the repo root after `pnpm build`.
No API key and no network: AI runs replay the committed fixture stores.

## 1. Three domains, one contract (2 min)

```sh
# The frozen contract the demo rides on:
grep -n "PLUGIN_API_VERSION" packages/plugin-api/src/version.ts   # 1.0.0
pnpm --filter @meridian/plugin-api test                           # incl. api-extractor verify
node apps/cli/dist/main.js plugins list                           # four adapters, one apiVersion ^1.0.0

# Markdown (P2), code (P7) — the pre-M3 domains, unchanged:
node apps/cli/dist/main.js ingest fixtures/corpora/markdown/links.md --out /tmp/md.json
node apps/cli/dist/main.js ingest packages/graph-core --adapter code --out /tmp/code.json
node apps/cli/dist/main.js cut /tmp/code.json --level 1
```

## 2. Conversations: skeleton, then AI (5 min)

```sh
# Deterministic skeleton — zero AI, byte-stable (the ADR-0034 floor):
node apps/cli/dist/main.js ingest fixtures/corpora/conversation/claude-two-topics.json \
  --adapter conversation --out /tmp/conv.json
node apps/cli/dist/main.js cut /tmp/conv.json --level 1     # exchanges

# AI enrichment as ordinary tagged deltas (replay = zero network):
node apps/cli/dist/main.js ai enrich /tmp/conv.json \
  --ai-mode replay --ai-provider mock --ai-fixtures fixtures/ai/enrich.conversation.fixtures.json \
  --out /tmp/conv-enriched.json
node apps/cli/dist/main.js cut /tmp/conv-enriched.json --level 1   # conv:topic layer, AI labels

# Idempotent: run it again — byte-identical, "unchanged" all the way down:
node apps/cli/dist/main.js ai enrich /tmp/conv-enriched.json --out /tmp/conv-enriched2.json
cmp /tmp/conv-enriched.json /tmp/conv-enriched2.json && echo idempotent

# The degraded floor is a real product, not an apology:
node apps/cli/dist/main.js ai enrich /tmp/conv.json --budget 0 --out /tmp/conv-floor.json
```

**Studio:** `pnpm dev`, open `/tmp/conv-enriched.json` (the saved-document
path). Zoom: session → **AI topics with AI names** → exchanges → messages.
Toggle the provenance filter: the graph falls back to evidence-only and
returns losslessly.

## 3. Arguments: the enrichment-reliant domain (4 min)

```sh
node apps/cli/dist/main.js ingest fixtures/corpora/argument/pedestrian-centers.md \
  --adapter argument --out /tmp/arg.json
node apps/cli/dist/main.js cut /tmp/arg.json --level 2      # sentences — the AI-less floor

node apps/cli/dist/main.js ai enrich /tmp/arg.json \
  --ai-mode replay --ai-provider mock --ai-fixtures fixtures/ai/enrich.argument.fixtures.json \
  --out /tmp/arg-enriched.json
node apps/cli/dist/main.js cut /tmp/arg-enriched.json --level 1
# claims/premises with arg:supports relations, each arg:cites-anchored to its paragraph
```

**Studio:** open `/tmp/arg-enriched.json`; the argument map overlays the
paragraphs; every AI node badges and filters.

## Talking points

- AI-extracted structure entered through **the same** proposal → delta →
  provenance pipeline the parsers use — no second write path was built for
  Phase 9 (ADR-0005 held).
- Every AI element names its reproducible call (provider, model, prompt
  version, input hash) and is globally filterable (ADR-0031).
- The plugin contract survived four domains without a reshaping change —
  the freeze is earned, not declared (chafe report §4).
