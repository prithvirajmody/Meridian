# M1 demo — the headless semantic core: ingest → mutate → cut

ROADMAP Phase 3 §13 / §3 demo for Milestone M1: *"`meridian cut --level N`
prints the visible node set + induced edges at any level"*, exercised
end-to-end — a real document is ingested by a plugin, mutated through the
op-based store, and resolved into semantic LOD cuts, all from the CLI with
zero pixels. Executed 2026-07-06 from the repo root after `pnpm build`.
Every command below was run for real; outputs are pasted verbatim (long
warning lists abridged with `…`).

## 1. Ingest a real markdown document

```
$ pnpm meridian ingest fixtures/corpora/markdown/links.md --out /tmp/m1-book.meridian.json
INGESTED fixtures/corpora/markdown/links.md
  adapter    markdown (@meridian/adapter-markdown)
  emitted    1 document · 0 deltas
  graphs 6 · nodes 11 · edges 5 · roots 1 · max depth 4
  provenance source 22 · derived 0 · ai 0
  wrote /tmp/m1-book.meridian.json
```

coverage proof (I5) says it covers all 6 leaves exactly once:

## 3. Mutate through the one write path

A 4-op delta (`fixtures/scripts/m1-errata.json`) adds an "Errata" section —
its own detail graph, a paragraph, and a `doc:links-to` edge to Chapter One —
applied atomically through the op-based store:

```
$ pnpm meridian mutate /tmp/m1-book.meridian.json --script fixtures/scripts/m1-errata.json \
    --out /tmp/m1-book-2.meridian.json --emit-delta /tmp/m1-errata.delta.json
OK /tmp/m1-book.meridian.json
  v0 → v1 · m1-demo · 4 ops (edge:add 1, graph:add 1, node:add 2) · touched 2 graphs, 3 nodes
      [0] graph:add g-errata "Errata"
      [1] node:add g-errata n-errata-p1 "Chapter One's anchor list was corrected."
      [2] node:add gzsmcby4mlkjz5jhnrlxm5nwcla n-errata "Errata"
      [3] edge:add gzsmcby4mlkjz5jhnrlxm5nwcla e-errata-ch1 n-errata → nqkl5gk7v5anlaitfnepx4l26lu [doc:links-to]

The chapter view now shows the new section and its induced edge; coverage
went from 6 to 7 leaves, still exact:

  coverage   7/7 leaves — covers ✓
  nodes (5):
    n-errata "Errata" (doc:section) · level · covers 1
    nbgs3istm5vt23xb6irkc6rfu2a "Appendix" (doc:section) · level · covers 1
    …
  induced edges (6):
    n-errata "Errata" → nqkl5gk7v5anlaitfnepx4l26lu "Chapter One" [doc:links-to] · weight 1 · ×1 (e-errata-ch1)
    …
```

At level 0 the new edge correctly *disappears*: both endpoints collapse into
the one visible root, and internal edges are excluded from the induced set
(ADR-0013 — internal density belongs to the node's summary, not the edge
list):

```
$ pnpm meridian cut /tmp/m1-book-2.meridian.json --level 0
  coverage   7/7 leaves — covers ✓
  nodes (1):
    nzsmcby4mlkjz5jhnrlxm5nwcla "Linked Document" (doc:section) · level · covers 7
  induced edges (0):
```

Abstraction *proposals* enter through this same write path: a deterministic
`AbstractionProvider`'s proposal becomes an ordinary tagged delta via
`applyProposal` (no second write channel, §8.1), and the next cut shows the
grouping — automated end-to-end in `apps/cli/test/proposal-cut.test.ts`.

## 5. Determinism (I6) and undo

Same request → byte-identical result:

```
$ pnpm meridian cut /tmp/m1-book-2.meridian.json --level 1 --json > /tmp/m1-cut-a.txt
$ pnpm meridian cut /tmp/m1-book-2.meridian.json --level 1 --json > /tmp/m1-cut-b.txt
$ cmp /tmp/m1-cut-a.txt /tmp/m1-cut-b.txt && echo byte-identical
byte-identical
```

And because the mutation is an invertible op delta, the whole edit undoes as
data — after which the cut is exactly the original again:

```
$ pnpm meridian invert /tmp/m1-errata.delta.json > /tmp/m1-undo.json
$ pnpm meridian mutate /tmp/m1-book-2.meridian.json --script /tmp/m1-undo.json --out /tmp/m1-book-restored.meridian.json
OK /tmp/m1-book-2.meridian.json
  v0 → v1 · m1-demo · 4 ops (edge:remove 1, graph:remove 1, node:remove 2) · touched 2 graphs, 3 nodes
  …
$ diff <(pnpm --silent meridian cut /tmp/m1-book.meridian.json --level 1 | tail -n +2) \
       <(pnpm --silent meridian cut /tmp/m1-book-restored.meridian.json --level 1 | tail -n +2) \
  && echo "level-1 cut identical after undo"
level-1 cut identical after undo
```

That is M1: a universal graph ingested by a plugin the core knows nothing
about, mutated only through invertible op deltas, and abstracted into
deterministic, provably-covering LOD cuts with aggregated edges — fully
tested, with zero pixels drawn.
