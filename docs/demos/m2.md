# M2 demo — the zoomable map: the book descent

ROADMAP §Milestones: *"M2 — The zoomable map (end of Phase 6). Zoom a
markdown book from 'one node' to 'every sentence' fluidly."* This is the
script for the recorded book-descent demo plus the live walkthrough at the
M2 review (ROADMAP Phase 6 §13). Recording is a human step (DRIVING-OPUS.md
§4 — feel judgments stay human); the script below is complete enough to
follow live, unrehearsed. The automated twins of every step already run in
CI (`apps/studio/e2e/navigation-descent.spec.ts`,
`navigation-interaction.spec.ts`, `transition-baselines.spec.ts`,
`tunables-panel.spec.ts`), so the demo demonstrates — it does not verify.

## Budgets this demo should visibly demonstrate

| Quantity | Budget | Where it is gated |
|---|---|---|
| Transition plan-to-settle | ≤ 300 ms (`transition-max-plan-to-settle-ms`) | ADR-0023 / §16.1; `navigation-descent.spec.ts` |
| Frame time during transitions | p95 ≤ 22 ms ≈ ≥ 45 fps (`transition-frame-p95-ms`) | ADR-0023; `transition-performance.spec.ts` |
| Anchor pixel drift per transition | < 8 px (`transition-anchor-drift-px`) | ADR-0024; `navigation-descent.spec.ts` |
| Plan computation, 5k-node cut diff | < 20 ms (`navigation-plan-5k-ms`) | `benchmarks/navigation-plan.bench.mjs` |
| Hysteresis | zero cut-flaps at a held threshold | ADR-0012; `controller.zoom.test.ts` |
| URL round-trip | restores the exact view | ADR-0025; `url.test.ts`, `navigation-interaction.spec.ts` |

## Setup

```sh
pnpm build && pnpm dev        # http://127.0.0.1:5173/
```

- Record at 1280×800 or larger, normal DPI, dark theme (the default).
- Plain URL for the recording itself (no `?debug=1`) — the debug HUD and
  tunables panel must be invisible in the product demo. A second, short
  segment *with* `?debug=1` shows the 6E panel (step 8).
- Corpus: `fixtures/corpora/markdown/links.md` — the M1 "Linked Document"
  book (chapters → sections → paragraphs, with cross-links that become
  induced edges at coarse levels).

## The script

### 1. Open the corpus (cold → first pixels)

Click **Open corpus** → `links.md`. Narrate the pipeline strip: sniff →
ingest → store → LOD → layout → render; the adapter chip reads
`markdown · 100%`. The initial view is the coarsest cut — the whole book as
one node (plus the breadcrumb bar showing the single root crumb).

### 2. Continuous zoom descent — the thesis (ADR-0024's Maps rule)

Place the pointer **on a chapter's corner, off-center** — never the middle
of the screen — and wheel-zoom in slowly. Narrate what makes this semantic
zoom, not camera zoom:

- At each threshold the node under the cursor is *replaced by its children*,
  which spawn from the parent's rectangle and cross-fade in (ADR-0023).
- The point under the cursor never slides: the world point maps through the
  refinement (ADR-0024) — hold the pointer still and let the descent pass
  book → chapters → sections → paragraphs ("every sentence").
- Cross-links between sections appear/aggregate as induced edges while their
  endpoints are collapsed, and dissolve to base edges at the finest cut.

Keep zooming past the finest level: the cut stops changing and the camera
merely magnifies (ADR-0025 saturation, up to `OVERZOOM_MAX = 4×`) — zoom
never changes scope. Zoom all the way back out: the book re-aggregates
through the same choreography, and at fit-all the view saturates again —
no context pop (symmetric explicitness).

Also demonstrate mid-flight retargeting: flick the wheel down then
immediately up — the flight reverses from its current interpolated state;
nothing queues, nothing snaps (ADR-0023 retarget-not-queue).

### 3. Expand/collapse in place (ADR-0012 overrides)

At the chapters view, click a chapter to select it and press **Space**: the
chapter expands *in place* into its sections while its siblings stay
collapsed — a mixed-granularity cut, still a covering antichain. Press
**Space** again to collapse it back. Point out this is an override on top
of the level-driven cut, not a level change.

### 4. Drill-in / drill-out — scope, not scale (ADR-0025)

Select a chapter and press **Enter**: the context *changes* — the chapter's
detail graph becomes the working root, framed at its coarsest level
(`FRAME_MARGIN = 10%`), and a new crumb appears in the breadcrumb bar.
Zoom around inside to show the sub-book behaves exactly like the book.
Press **Escape** (or click the parent crumb): the previous view is restored
*exactly* — camera, zoom, and any Space-overrides included. Narrate the
distinction the ADR ends the debate on: wheel = scale, Enter/Esc = scope;
neither ever triggers the other.

### 5. Search and fly-to

Type a distinctive word from a deep paragraph (for `links.md`: `appendix`)
into the search box. Pick a hit: the camera flies to the covering node of
that result within the current context — focus is set, no drill, no zoom
level change. Show that search is context-scoped by drilling into a chapter
and searching again: hits outside the context are absent.

### 6. URL share / restore (ADR-0025 — "where I am" is a value)

At a distinctive mid-descent view (drilled one level, partially zoomed,
one expand override), copy the URL — the fragment carries
`#g=…&ctx=…&z=…&cam=…&focus=…&ov=…`. Open it in a **new tab**: the exact
view is restored — same cut, same camera, same override — resolved fresh
(hysteresis residue is deliberately not serialized). This is the seam P12
presence/bookmarks will reuse.

### 7. Minimap

Zoom in deep, then point at the minimap (bottom-right): the viewport
rectangle tracks the camera against the whole layout's bounds. Click a far
corner of the minimap: the camera centers there at the same scale — a pan,
never a cut change. Zoom out; the rectangle grows until it hugs the whole
map at fit-all.

### 8. (Debug segment) The 6E tuning panel

Reload with `?debug=1`. Open **Tunables** (top-right, next to the FPS/heap
HUD): every ADR-named constant is live — `BASE_TRANSITION_MS`,
`CROSSFADE_MS`, the three degrade thresholds, `ANCHOR_SNAP`, `OVERZOOM_MAX`,
`FRAME_MARGIN`, `KEY_ZOOM_FACTOR`, `READABLE_LEAF_PX` — plus the view-only
shared easing. Drop `BASE_TRANSITION_MS` to 120 and zoom: the next
transition is visibly snappier, no reload. Set `MAX_ANIMATED_NODES` to 0
and zoom: every transition degrades to the plain cross-fade — the degrade
rule made visible. Click **Reset to ADR defaults** and confirm the `*`
markers clear. Narrate: the panel edits a session copy; the shipped
defaults are the frozen ADR values (`NAV_TUNABLE_DEFAULTS`).

## Close

End on the full descent one more time, silent, in one continuous gesture —
book → sentences → book. That single shot *is* M2: zooming changes the
abstraction itself, the anchor holds, and nothing ever janks past the
budget rail.
